What you can do

  • Paste JSON anywhere on the page, or drop a .json file on the input.
  • Paste a link to load JSON from a URL. The server has to allow requests from other websites (CORS).
  • Add request headers (e.g. a tenant id or API key) under Headers; tick them on or off as needed.
  • Escaped JSON such as {{ escapedExample }} is unescaped automatically.
  • Explore it as a tree or as highlighted text. Sort keys, change indentation, copy or download.
  • Format or minify the input itself. Click an error to jump to it.
  • Nothing is uploaded. History is stored only in this browser.
  • Works offline, and can be installed as an app from the browser menu.
